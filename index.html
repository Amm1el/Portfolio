Transcripter: Transcript Management and Processing System

An internal FSU IT Services system built for the Office of Admissions. It replaces fragmented, manual transcript processing with a structured workflow. Staff submit transcript records, track processing progress, and manage employee roles, and administrators get an analytics view of submission trends and processing activity.

Key features: role-based access control, a submission form with dynamic validation, a real-time dashboard where staff sort, filter, and manage records, a log of every create, edit, and delete, multi-document support, and admin tools for managing users.

The hard parts were keeping audit logs accurate across every action, handling sensitive information securely, building interfaces staff find intuitive, and designing a flexible role-based system. Next on the list: automated document processing, integration with more university systems, better search and filtering, richer activity monitoring, and reporting tools for administrators.

Predicting Seizures with Graph Neural Networks

Undergraduate research with Dr. Yushun Dong in FSU's Department of Computer Science, documented in a 2025 Undergraduate Research Opportunity Program (UROP) poster. It tests whether combining graph neural network (GNN) models improves real-time seizure prediction from EEG.

EEG recordings become functional brain networks, with EEG channels as nodes and edges from Pearson correlation and mutual information. Deep Graph Infomax learns node embeddings, and a GNN-based temporal model extracts features over time. Preliminary results show accuracy in the mid-70% range, with better F1 and AUC scores than single-GNN models.

PyTorch, PyTorch Geometric, Deep Graph Infomax, EEG
